# 📚 Kişisel Kütüphane Takip Uygulaması

Bu proje, kullanıcıların okudukları ve okuyacakları kitapları düzenli bir şekilde yönetmelerini sağlayan Python tabanlı, kullanımı kolay bir konsol uygulamasıdır.

## 🚀 Özellikler

- 📖 **Kitap Listeleme:** Tüm kitapları veya filtreli şekilde (okunmuş / okunmamış) görüntüleme.
- ➕ **Yeni Kitap Ekleme:** Kitap adı ve yazar bilgisi girerek kütüphaneye veri ekleme (boş girdi kontrolü ile).
- 🔄 **Durum Güncelleme:** Kitapların okuma durumunu (`okundu` / `okunmadı`) hızlıca değiştirme.
- 🗑️ **Kitap Silme:** Listedeki kitapları sıra numarası üzerinden silme.
- 💾 **Kalıcı Veri Depolama:** Tüm verileri `JSON` formatında otomatik kaydetme ve uygulama her açıldığında geri yükleme.

## 🛠️ Teknolojiler & Araçlar

- **Dil:** Python 3
- **Veri Formatı:** JSON

## 💻 Nasıl Çalıştırılır?

1. Proje dosyalarını bilgisayarınıza indirin veya klonlayın:
   git clone [https://github.com/rumeysaferhankara-code/kisisel-kutuphane-uygulamasi.git](https://github.com/rumeysaferhankara-code/kisisel-kutuphane-uygulamasi.git)

2. Terminal veya komut satırından proje klasörüne gidin ve uygulamayı çalıştırın:
